# ServerHelm

SSH terminal, SFTP file manager and live server dashboard in one Windows desktop app.

This repository only hosts ServerHelm's installers and update feed; the source code is private.

## Install

1. Download **[ServerHelm-setup.exe](https://github.com/silentrebel123/ServerHelm-releases/releases/latest/download/ServerHelm-setup.exe)** (latest release).
2. Run it. It installs for your Windows user only, no admin rights needed.
   If Windows SmartScreen says "Windows protected your PC", choose **More info → Run anyway**.

## Updates

ServerHelm checks this repository for a new version on start and every few hours, and offers
**Install and restart** in **Settings → App updates**. Every update is signed; ServerHelm refuses
anything not signed with its release key.

All versions and release notes: [Releases](https://github.com/silentrebel123/ServerHelm-releases/releases).
